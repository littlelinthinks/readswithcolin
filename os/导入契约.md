# 豆包书单 · 导入契约（READS WITH COLIN OS）

> 本契约定义「豆包整理的书单」导出成 Excel/CSV 后，被 OS 一键读入的格式。
> 目的：让上千套书随时增量进入 OS，且**不丢数据、不编造、可回滚**。

## 一、文件要求

- 格式：**Excel (.xlsx)** 或 **CSV（UTF-8 带 BOM）**。
- 单 Sheet，Sheet 名必须是 **`books`**（其它 Sheet 会被忽略）。
- 第一行是列头（下表英文），顺序随意，缺列也能导入（空着即可）。
- 数组类字段用 **`；`**（中文分号）分隔，例如 `topics` 填 `认知偏误；决策`。

## 二、列头清单（与数据库字段一一对应）

| 列头 | 含义 | 类型 | 规则 |
|---|---|---|---|
| `id` | 书籍 ID | 文本 | **可选**。有则原样保留（用于增量更新）；无则系统补发 `BK-xxxx`。**切勿手填自创 ID** |
| `title` | 书名 | 文本 | **必填**。缺书名的行会被跳过（不写库） |
| `titleEn` | 英文书名 | 文本 | 可选 |
| `author` | 作者（展示用） | 文本 | 推荐填。单作者直接写；多作者也可在此用 `、` 隔开 |
| `authors` | 多作者实体 | 数组`；` | 可选。填了会以 `；` 拆成作者列表；留空则按 `author` 拆分 |
| `translator` | 译者 | 文本 | 可选 |
| `isbn` | ISBN | 文本 | 推荐填。**缺 ISBN 且缺作者 → 标需复核** |
| `publisher` | 出版社 | 文本 | 可选 |
| `year` | 出版年 | 数字 | 可选，空着即可 |
| `language` | 语言 | 文本 | 如 `中文` / `英文` |
| `edition` | 版次 | 文本 | 如 `第3版` |
| `country` | 国别 | 文本 | 可选 |
| `category` | 分类 | 文本 | 可选 |
| `topics` | 主题标签 | 数组`；` | 如 `认知偏误；决策` |
| `startDate` | 开始阅读日期 | 日期 | `YYYY-MM-DD` |
| `finishDate` | 完成日期 | 日期 | `YYYY-MM-DD` |
| `status` | 状态 | 枚举 | `to_read`(想读) / `reading`(在读) / `completed`(读完) / `rereading`(重读)。缺省 `to_read` |
| `format` | 形式 | 文本 | 如 `纸质书` / `电子书` / ` audiobook` |
| `readingCount` | 读过几遍 | 数字 | 可选 |
| `rating` | 评分 | 数字 0-5 | 可选 |
| `totalPages` | 总页数 | 数字 | 可选 |
| `oneLineSummary` | 一句话总结 | 文本 | 可选 |
| `coreQuestion` | 核心问题 | 文本 | 可选 |
| `coreIdeas` | 核心思想 | 数组`；` | 一行一条，用 `；` 隔开 |
| `source` | 数据来源 | 文本 | 建议填 `豆包`，便于溯源 |
| `relatedBookIds` | 关联书 ID | 数组`；` | 填其它书的 `id`，用于跨书连接 |
| `notes` | 备注 | 文本 | 可选 |

> 内部字段 `createdAt` / `updatedAt` / `needsReview` / `reviewReasons` **不需要填**，由系统维护。

## 三、导入行为（系统侧）

1. **导入前自动快照**：每次导入先在本地备份全量数据，Settings → 回滚上次导入 可一键还原。
2. **增量幂等**：有 `id` 的行 = 更新该书；无 `id` 的行 = 新增。不会删除任何已有书籍。
3. **缺书名**：整行跳过，计入「跳过」统计。
4. **缺 ISBN / 作者**：该书标记 `needsReview = true`，并在 Books 列表「需复核」里出现，待你补充。
5. **未知列**：表里有但上表没列的字段也会被原样保留，不丢数据。
6. **进度与报告**：1000+ 行导入时弹进度条；结束给出 新增 / 更新 / 跳过 / 需复核 汇总。

## 四、怎么拿到模板

OS 内：Settings → **下载导入模板**，即得一个带全部表头的空 Excel。
